## Known data traps

One line per trap: what goes wrong, how to spot it, the fix. Add a line every time something fails without an error message.

## Working rules

- Search only inside named folders, never the whole project root on a cloud drive.
- New numbers come from a script that writes to the results file. No hand-typed numbers in the draft.
- References come from a database record with a DOI, never from memory.
- Report what was checked and how. "Done" means the acceptance criteria were met.
