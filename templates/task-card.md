# Task card: short name

| Field | |
|---|---|
| Status | Not started / In progress / In review / Done |
| Depends on | Cards that must finish first |
| Model | Strong model (needs judgement) or fast model (mechanical) |

## Goal

One or two sentences: what will be true when this card is done.

## Context

What the worker needs that is not already in the project instructions. Put facts the coordinator has already checked here, so the worker does not redo them.

## Steps

1.
2.

## Acceptance criteria

How the reviewer will decide the card is done. Make each one checkable: a file exists, a number matches the results file, a test passes, a figure shows what it should.

## Do not

Files not to touch, decisions not to make, shortcuts not to take.

## Report back

What changed, what was checked, and anything that needs a decision.
